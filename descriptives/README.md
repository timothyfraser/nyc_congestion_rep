## Key Output Files

### [`att.csv`](att.csv) ⭐ **OVERALL STATISTICS**

**Simplest summary file** - Contains the key findings in one place: Average Treatment Effects (ATT) for each geographic area plus an overall combined estimate. **Start here for quick answers.**

**Generated by**: `get_att()` function called in [`02_descriptives.R`](02_descriptives.R) (lines 236-272)

**What it contains**:
- **Multiple rows** showing Average Treatment Effects (ATT) at different geographic levels:
  - **Main Geographic Areas:**
    - **CRZ** (Congestion Relief Zone) - Model M9
    - **NYC** (5 Boroughs) - Model M6
    - **CBSA** (Metro Area) - Model M3
    - **Overall** (Combined across all areas) - Model Combined
  - **County-Specific Estimates:** One row per county (e.g., Bronx, Queens, Kings, New York, Richmond, Nassau, Suffolk, and other counties in the metro area) - Model Mixed
  - **Regional Aggregations:**
    - **Long Island** (Kings, Queens, Nassau, Suffolk combined) - Model Mixed
    - **Long Island (Nassau & Suffolk)** (just Nassau and Suffolk counties) - Model M3

**Key Variables**:
- `area`: Geographic area (CRZ, NYC, CBSA, Overall, county names, or regional aggregations like Long Island)
- `model`: Model identifier (M9, M6, M3, Combined, or Mixed)
- `att`: **Average Treatment Effect** - Change in PM2.5 (μg/m³) - negative = reduction
- `se_att`: Standard error of ATT (μg/m³)
- `stars`: Statistical significance indicators (***, **, *, ., or empty)
- `yhat1`: Average Predicted PM2.5 WITH policy (μg/m³)
- `yhatse1`: Standard error of yhat1 (μg/m³)
- `yhat0`: Average Predicted PM2.5 WITHOUT policy - counterfactual (μg/m³)
- `yhatse0`: Standard error of yhat0 (μg/m³)

**Use this file when**:
- You need a quick summary of the main findings
- You want to compare effects across geographic areas
- You need the overall treatment effect estimate
- You're writing a summary or abstract

**📖 For detailed usage guide, see the [Journalist Guide](../docs/journalist_guide.md)**

### [`qi_by_sensordate.csv`](qi_by_sensordate.csv) ⭐ **SITE STATISTICS**

**Main data file** containing sensor-date level observations with treatment effects, predictions, and observed values. This is the most granular and complete dataset for analysis.

**Generated by**: `get_qi_by_sensordate()` function (called in [`02_descriptives.R`](02_descriptives.R))

**What it contains**:
- Treatment effects at the sensor-date level (not aggregated)
- Predicted values for both treated (`yhat1`) and counterfactual (`yhat0`) scenarios
- Observed PM2.5 concentrations for comparison
- Results from the best models for each geographic area:
  - **M3**: CBSA (Core-Based Statistical Area) - fully specified model
  - **M6**: NYC (5 Boroughs) - fully specified model  
  - **M9**: CRZ (Congestion Relief Zone) - fully specified model

**Key Variables**:
- `diff`: Treatment effect (difference between treated and counterfactual predictions) in μg/m³
- `percentchg`: Percentage change in PM2.5 compared to counterfactual
- `yhat1`: Predicted PM2.5 with treatment (μg/m³)
- `yhat0`: Predicted PM2.5 without treatment - counterfactual (μg/m³)
- `sediff`, `se1`, `se0`: Standard errors for uncertainty quantification
- `model`: Model identifier (M3, M6, or M9)
- `aqs_id_full`: Sensor identifier
- `date`: Date of observation
- `area`: Geographic area (cbsa, nyc, or crz)

**Use this file when**:
- You need sensor-level or daily-level analysis
- You want to compare predicted vs observed values
- You need to calculate custom aggregations
- You want the most detailed view of treatment effects

**📖 For detailed usage guide, see the [Journalist Guide](../docs/journalist_guide.md#-detailed-data-qi_by_sensordatecsv)**

### [`effects.csv`](effects.csv)
**Aggregated results file** containing treatment effect estimates summarized at different levels (overall, per area, per sensor, per week, per month). 

**Note**: For sensor-date level data with observed values and more granular analysis, use [`qi_by_sensordate.csv`](#qi_by_sensordatecsv-⭐-site-statistics) instead. For quick summary, use [`att.csv`](#attcsv-⭐-overall-statistics).

**📖 For detailed documentation on using this file, see the [Journalist Guide](../docs/journalist_guide.md)** - includes column descriptions, common queries, code examples, and interpretation guidance.

**Structure:**
- `model`: Model identifier (cbsa1-3, nyc1-3, crz1-3) - see [Understanding Model Names](../docs/journalist_guide.md#understanding-model-names) in the journalist guide
- `type`: Effect aggregation level ("overall", "per_area", "per_sensor", "per_week", "per_month") - see [Understanding Effect Types](../docs/journalist_guide.md#understanding-effect-types)
- `att`: Average Treatment Effect on the Treated (change in PM2.5 in μg/m³) - see [Interpreting Results](../docs/journalist_guide.md#interpreting-results)
- `se_att`: Standard error of ATT - used to calculate [confidence intervals](../docs/journalist_guide.md#2-calculate-95-confidence-intervals)
- `stars`: Statistical significance indicators (***, **, *, ., or empty) - see [Statistical Significance](../docs/journalist_guide.md#statistical-significance)
- `spec`: Model specification level (1=Basic, 2=+Weather, 3=+Demographics) - see [Specification Levels](../docs/journalist_guide.md#specification-levels)
- Conditional columns based on `type`:
  - `area`: Geographic area (for type="per_area")
  - `week`: Week number (for type="per_week")
  - `month`: Month number (for type="per_month")
  - `aqs_id_full`: Sensor identifier (for type="per_sensor")

For complete column descriptions and examples, see the [Understanding the Columns](../docs/journalist_guide.md#understanding-the-columns) section in the journalist guide.

### [`panel_daily_nyc.rds`](panel_daily_nyc.rds)
Panel dataset with daily observations:
- Air quality measurements (PM2.5)
- Weather variables (temperature, humidity, wind, precipitation, cloud cover)
- Census demographics (population density, income, race/ethnicity)
- Geographic classifications (area, county, within CRZ)
- Temporal variables (date, week, day, month)
- Distance variables (to CRZ, to nearest highway)
- Background concentration levels

### [`models.rds`](models.rds)
RDS file containing 9 fitted linear regression models:
- `cbsa1`, `cbsa2`, `cbsa3`: Core-Based Statistical Area (Metro Area) models
- `nyc1`, `nyc2`, `nyc3`: NYC 5 Boroughs models
- `crz1`, `crz2`, `crz3`: Congestion Relief Zone models
- Each numbered model (1-3) represents increasing specification complexity

## Scripts

Scripts are numbered in execution order (00-08) with utility scripts prefixed with `ZZ_`.

### Core Scripts

#### [`00_functions.R`](00_functions.R)
Core utility functions used throughout the analysis:
- `pm25_aqi()`: Converts PM2.5 concentration to Air Quality Index (AQI)
- `cor_tidy()`: Creates tidy correlation matrices
- `tidier()`: Formats model output with significance stars
- `get_vif()`: Calculates Variance Inflation Factors
- `get_gof()`: Extracts goodness-of-fit statistics
- `get_table()`: Creates formatted HTML tables from model results
- `get_lines()`: Generates time series plots
- `get_many_models()`: Fits multiple regression models (9 total)
- `get_yhat()`: Generates predicted values from models
- `get_simeffects()`: Simulates treatment effects with uncertainty
- `get_effects()`: Calculates treatment effects
- `get_att()`: Computes Average Treatment Effect on the Treated (ATT)
- `get_qis()`: Main function that generates all effect estimates (overall, per area, per sensor, per week, per month)
- `get_qi_by_sensordate()`: Generates sensor-date level treatment effects with observed values

#### [`01_dataset.R`](01_dataset.R)
Creates the panel dataset ([`panel_daily_nyc.rds`](panel_daily_nyc.rds)) from raw data components:
- Loads air quality monitoring sites
- Calculates distances (to CRZ, to nearest highway)
- Joins air quality, weather, and census data
- Creates temporal variables (week, day, month)
- Classifies areas (cbsa, nyc, crz)
- Filters and prepares data for analysis

#### [`02_background.R`](02_background.R)
Compares sites for background concentration levels:
- Identifies background monitoring sites (Hunterdon, Middlesex, Morris, Passaic counties)
- Calculates mean background PM2.5 concentration
- Visualizes background vs. CRZ concentrations
- Used to select appropriate background sites for the analysis

#### [`02_descriptives.R`](02_descriptives.R)
Generates descriptive visualizations and creates key outputs:
- Creates time series plots of daily air quality
- Visualizes day-of-week patterns
- Creates [`models.rds`](models.rds): Saves fitted model objects
- **Generates [`effects.csv`](effects.csv)**: Aggregated results file with all treatment effects
- **Generates [`qi_by_sensordate.csv`](qi_by_sensordate.csv)**: Primary data source with sensor-date level treatment effects and observed values
- **Generates [`att.csv`](att.csv)**: Quick summary file with ATT by area

#### [`03_maps.R`](03_maps.R)
Creates spatial visualizations of treatment effects:
- Maps treatment effects per sensor location
- Visualizes effects across geographic areas
- Combines population density, roads, and monitoring sites
- Generates publication-quality maps

#### [`04_effects.R`](04_effects.R)
Visualizes and reports key treatment effects:
- Creates bar plots of overall ATT effects by model
- Generates weekly effects plots
- Analyzes relationship between vehicle entries and air quality changes
- Produces combined visualizations
- Outputs figures: [`fig/fig_att.png`](fig/fig_att.png), [`fig/fig_att_weekly.png`](fig/fig_att_weekly.png), [`fig/fig_att_vehicle_entries.png`](fig/fig_att_vehicle_entries.png)

#### [`05_numbers.R`](05_numbers.R)
Generates key numbers for paper text:
- Calculates sample sizes (dates, sensors, hours)
- Computes missing data statistics
- Extracts effect estimates for abstract/results
- Calculates VIF (Variance Inflation Factor) statistics
- Provides specific numbers cited in the paper

#### [`06_changes.R`](06_changes.R)
Visualizes changes over time:
- Analyzes weekly vehicle entry trends
- Calculates percent changes in vehicle entries
- Calculates percent changes in treatment effects over time
- Compares changes across different metrics

#### [`07_synth.R`](07_synth.R)
Placeholder/minimal script (currently contains only a data read statement).

#### [`08_media.R`](08_media.R)
Script for media coverage inquiries:

## Model Specifications

The analysis uses 9 models organized by geographic scope and specification complexity:

### Geographic Scope
- **CBSA** (cbsa1-3): New York City Metropolitan Area (Core-Based Statistical Area)
- **NYC** (nyc1-3): New York City 5 Boroughs only
- **CRZ** (crz1-3): Congestion Relief Zone only

### Specification Levels
1. **Basic Model** (spec=1): Treatment + temporal controls + background concentration + distance to roads
2. **+Weather** (spec=2): Adds weather controls (temperature, humidity, wind, precipitation, cloud cover)
3. **+Demographics** (spec=3): Adds demographic controls (population density, income, race/ethnicity) - **most complete**

For more details on model specifications and which to use, see the [Understanding Model Names](../docs/journalist_guide.md#understanding-model-names) section in the journalist guide.

## Workflow

Typical execution order:
1. [`01_dataset.R`](01_dataset.R) - Create panel dataset
2. [`02_background.R`](02_background.R) - Select background sites (if needed)
3. [`02_descriptives.R`](02_descriptives.R) - Generate [`qi_by_sensordate.csv`](qi_by_sensordate.csv), [`att.csv`](att.csv), [`effects.csv`](effects.csv) and [`models.rds`](models.rds)
4. [`03_maps.R`](03_maps.R) - Create spatial visualizations
5. [`04_effects.R`](04_effects.R) - Create effect visualizations
6. [`05_numbers.R`](05_numbers.R) - Extract key numbers for paper
7. [`06_changes.R`](06_changes.R) - Analyze temporal changes

- Treatment period: January 6, 2025 - June 1, 2025
