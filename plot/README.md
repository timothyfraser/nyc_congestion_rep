# `/plot` Descriptive Visualization Plotting Scripts

**Author**: Danni Lu (PhD Student)

This folder contains R scripts used to generate visualizations for the NYC Congestion Pricing policy evaluation paper. These scripts were used to produce content for **Figures 3 and 4** in the publication.

## Contents

The folder contains various plotting scripts including:
- Boxplot analyses (multiple variations)
- Monthly trend visualizations
- Single monitor station analyses
- Background data visualizations
- Wind rose plots
- Hourly PM2.5 analyses

Note: This folder contains both draft and final work. The scripts are provided as-is for reference.
