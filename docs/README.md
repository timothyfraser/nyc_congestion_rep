# `/docs`

This folder contains additional documentation for the NYC Congestion Pricing policy evaluation study.

## Contents

- **[README](README.md) - You're here!
- **[Journalist Guide](journalist_guide.md)** - Comprehensive guide for data journalists and researchers on how to use the key data files from this study, including code examples, common queries, and interpretation guidance.

## Overview

The documentation in this folder is designed to help external users understand and work with the study's data and findings. The journalist guide provides detailed information about:

- Key data files (`att.csv`, `qi_by_sensordate.csv`, `effects.csv`)
- How to interpret treatment effects and statistical significance
- Citation information

For technical documentation about scripts and analysis workflows, see the README files in the respective analysis folders (`descriptives/`, etc.).
